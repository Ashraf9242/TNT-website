# TNT-website

> تحديث بطلب المستخدم: الواجهة المتاحة حاليًا عربية فقط. زر اللغة والروابط الإنجليزية مخفية، ومسارات /en تعيد التوجيه مؤقتًا إلى الصفحة العربية المقابلة. المحتوى الإنجليزي محفوظ للمستقبل؛ لإعادته أضف en إلى activeLanguages في src/data/site.ts بعد الاعتماد. أُزيل شريط التأسيس العلوي وقسم طلب السعر المتكرر قبل التذييل.

# تشغيل موقع TNT

المشروع داخل هذا المجلد، إلى جانب المواد الأصلية التي لم تُعدّل. الموقع نسخة مراجعة محلية: 11 صفحة لكل لغة، عرض على الخادم، عربية RTL وإنجليزية LTR، مظهر حسب الجهاز مع حفظ الاختيار، نموذج طلب عرض سعر، وصور وخطوط محلية.

## التشغيل في Windows / VS Code

يتطلب Node.js حديثًا متوافقًا مع Astro 7 (تم الاختبار بـ Node 25.2.1). الإصدارات الدقيقة في package-lock.json. استخدم npm.cmd في PowerShell إذا منعت سياسة تنفيذ السكربتات npm.ps1.

```powershell
npm.cmd ci
Copy-Item .env.example .env
npm.cmd run dev -- --port 4321
```

افتح http://localhost:4321/ar أو http://localhost:4321/en. يستخدم Astro 7 خادم تطوير مُدارًا؛ `npx.cmd astro dev status` لعرضه و`npx.cmd astro dev stop` لإيقافه.

```powershell
npm.cmd run check
npm.cmd run test
npm.cmd run build
npm.cmd run start
```

أمر start يشغّل ناتج البناء ويقرأ .env عبر Node؛ اضبط HOST وPORT في البيئة عند الحاجة. لا يوجد نشر تلقائي أو حساب خارجي مرتبط.

## الصفحات والمحتوى

المسارات: /ar و/en، ثم about، services، installation، maintenance، cleaning، contracts، systems، clients، pricing، contact. تبديل اللغة يحتفظ بالصفحة نفسها. صفحات المشاريع والأسئلة غير منشورة؛ تظهر مكوناتها عند إضافة بيانات معتمدة وكاملة فقط إلى pendingCollections في src/data/site.ts.

- src/data/source.json: النصوص الأصلية المستخرجة؛ لا تعدّلها لتصحيح صياغة أو ترجمة.
- src/data/content.ts: توزيع النصوص والخدمات والأنظمة والأسعار وشعارات العملاء.
- src/data/site.ts: بيانات الاتصال، عناوين التنقل، نصوص الأزرار والحقول، والمجموعات المستقبلية.
- src/styles/global.css: رموز الألوان والمسافات والخطوط والمظهرين.
- src/components: مكونات الواجهة المشتركة.
- src/pages/[lang]/[...slug].astro: توزيع الصفحات على المسارات.
- نصوص المحتوى موزعة في `src/data/content.ts`، بينما ملفات المصدر الأصلية خارج مجلد الموقع.
- docs/client-approval.md: المعلومات والتصحيحات المطلوبة من الشركة.
- docs/drafts.json: عناوين SEO وترجمات مقترحة غير مستوردة وغير منشورة.

العقود الأصلية عربية فقط، ولذلك يبقى نصها عربيًا داخل الصفحة الإنجليزية حتى اعتماد الترجمة. تكرار الصيانة تحت التركيب الإنجليزي وMusact محفوظان في نسخة المراجعة ومسجلان للتصحيح. أرقام الشركة والأسعار من العرض، دون تأكيد خارجي لصلاحيتها. لا تنشر قبل الاعتماد.

## إعداد البريد

املأ SMTP_HOST وSMTP_PORT وSMTP_SECURE وSMTP_USER وSMTP_PASS وSMTP_FROM في .env. QUOTE_TO افتراضيًا بريد الشركة الموجود بالعرض. جميع مفاتيح SMTP خاصة بالخادم؛ لا تستخدم PUBLIC_ للأسرار. استخدم خدمة SMTP موثقة ومُهيأة بـ TLS ومرسل مسموح له بالإرسال. لا توجد أسرار في .env.example.

/api/quote يتحقق من الحقول وطولها وقيم الخدمات والأنظمة، يمنع الطلبات من أصل مختلف، يقيد الجسم بـ16KB، ويستخدم حقلًا خفيًا وحدًا قدره 5 محاولات لكل 10 دقائق لكل عنوان اتصال. الحد داخل ذاكرة عملية واحدة، وليس موزعًا. في نشر متعدد النسخ استخدم تحديد المعدل لدى البوابة أو مخزن مشترك؛ لا توجد قاعدة بيانات هنا. لا تفعل TRUST_PROXY إلا عندما تضبط البوابة لمسح وإعادة كتابة X-Forwarded-For ولا تسمح بالوصول المباشر إلى التطبيق.

غياب إعدادات البريد ينتج 503 وخطأ واضح ويحافظ على الحقول في الصفحة المفتوحة. نجاح الواجهة يحصل فقط عند إقرار الخادم بقبول SMTP للرسالة؛ هذا لا يضمن وصولها لصندوق الوارد. لا تُسجل بيانات الطلب في السجلات ولا في localStorage. بعد إعادة تحميل الصفحة لا تُحفظ الحقول. في غياب JavaScript استخدم روابط الهاتف والبريد؛ زر النموذج لا يُفعّل إلا بعد تهيئة التحقق.

لم يُختبر إرسال بريد حقيقي ولم تُرسل رسالة إلى الشركة. حالة النجاح اختُبرت باستجابة محاكاة داخل أداة الاختبار فقط.

## النطاق والفهرسة

PUBLIC_SITE_URL فارغ عمدًا؛ ضع النطاق الحقيقي الكامل عند توفره. عند ضبطه تتولد canonical وروابط hreflang ووسوم المشاركة بعناوين مطلقة. لا تتولد روابط على نطاق مخترع. PUBLIC_ALLOW_INDEXING=false وPUBLIC_CONTENT_APPROVED=false افتراضيًا؛ تبقى صفحات المعاينة noindex ونص robots يمنع الزحف وsitemap فارغ.

بعد اعتماد النصوص والحقوق والبيانات، وتطبيق التصحيحات المعتمدة، اضبط المفتاحين إلى true وأعد البناء مع PUBLIC_SITE_URL الصحيح. تُفعّل عندها الفهرسة وsitemap والبيانات المنظمة المؤكدة فقط. المتغيرات PUBLIC_ تُقرأ وقت البناء؛ تغييرها يتطلب إعادة البناء. noindex ليس حماية وصول؛ النسخة للمراجعة المحلية، وأي معاينة خارجية تحتاج حماية وصول من مزود الاستضافة.

## الصور والخطوط

نسخ WebP بأحجام 480 و960 و1600 مع srcset وأبعاد ثابتة. صورة الواجهة تُحمّل بأولوية والباقي مؤجل. الشعار النهاري JPG، والشعار الليلي PNG المرسل لاحقًا من المستخدم؛ النهاري على سطح فاتح والليلي بخلفية شفافة على سطح الموقع الداكن، وبنسبهما الأصلية. الخطوط IBM Plex محلية بثلاثة أوزان 400 و500 و600، والرخص في public/licenses. راجع docs/asset-manifest.json وdocs/sources-and-licenses.md.

الفيديو الأصلي 97.9MB، والنسخة المحسنة 3.57MB؛ غير موصول بالصفحات إلى حين مراجعة الصوت والترجمة. فُحصت لقطاته بصريًا، ولم يتوفر مشروع باكيج مصوّر مناسب للواجهة. لا توجد صور خارجية أو مولدة أو أسماء مشاريع مختلقة.

## الاختبارات

```powershell
npm.cmd run verify:content
npm.cmd run test:site
```

اختبارات المتصفح تتطلب تشغيل الخادم على 4321 وChromium. اضبط CHROMIUM_PATH لمسار المتصفح المحلي أو TEST_BASE_URL لخادم الاختبار. المسار الافتراضي في scripts/test-site.mjs خاص بهذا الجهاز. يمكن تثبيت Chromium بـ `npx.cmd playwright install chromium` ثم تعديل المسار أو استخدام المتصفح الافتراضي في سكربت الاختبار. لا تشغّل اختبار النموذج على خادم بريد حي، إذ يختبر 503 عند عدم الإعداد. جميع بيانات الاختبار وهمية.

لا يوجد إعداد lint مستقل؛ Astro check وTypeScript هما فحصا الشيفرة. شغّل `npm.cmd run check` و`npm.cmd run build` بعد تثبيت الاعتمادات.
